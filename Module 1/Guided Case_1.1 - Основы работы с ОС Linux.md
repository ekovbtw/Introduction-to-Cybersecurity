Представим типичный сценарий: вы подключились к серверу по **SSH**. На сервере нет рабочего стола, проводника, графического редактора файлов или кнопок. Есть только текстовый интерфейс, через который вам нужно понять, где вы находитесь, какие файлы рядом, где лежит проект, как открыть лог, как скопировать конфигурацию перед изменением и как не удалить лишнее.
Мы с вами разберём базовый набор действий, который нужен в таких ситуациях:

- ориентироваться в файловой системе
- понимать, из каких частей состоит команда
- читать справку по утилитам 
- создавать, копировать, перемещать и удалять файлы
- читать обычные файлы и логи
- перенаправлять вывод команд в файл
- отличать shell-переменные от переменных окружения
- узнать, что такое **.env** и зачем он нужен

## **Зачем нужен терминал**
Терминал используется там, где не нужен графический интерфейс или его нет. Также терминальный вход может быть доступен напрямую в системе через **tty** - текстовую консоль без графического интерфейса. В Linux можно быстро переключаться между **tty**. Когда вы запустите виртуальную машину, по умолчанию будет открыта сессия в **tty1**, но если вам нужно создать ещё одну сессию, выполните сочетание клавиш **Ctrl+Alt+(F1-F6)

Задачи, которые удобно выполнить через терминал: 
1. подключение к удаленному серверу через ssh 
2. посмотреть содержимое конфигурационного файла 
3. дублировать директорию 
4. проверить значение переменной окружения 
5. записать вывод команды в файл 

Когда пользователь вводит строку в терминале, внутри происходит несколько шагов.

Определим понятия: 
1. Терминал - интерфейс для текстового ввода/вывода. GNOME, Windows Terminal, Konsole
2. Shell - командная оболочка, она читает введенную строку, интерпретирует ее и запускает команды. Bash, zsh, fish, sh
3. Команда - то, что пользователь просит выполнить. Это может быть отдельная программа, встроенная команда shell или ярлык оболочки(alias). pwd, cd, ls, echo
4. Опция - модификатор поведения команды, обычно начинается с - или --. ls -l, ls --all 
5. Аргумент - значение, с которым работает команда. Часто путь к файлу. cat file.txt
Alias - ярлык оболочки, который можно задать для того, чтобы не вводить более длинную или сложную команду. К примеру systemctl suspend уводит систему в режим сна, можно заменить на zzz, используя alias zzz = "systemctl suspend". Если необходимо убрать alias есть команда unalias. 
Опции также принято называть флагами. 
Терминал лишь передает текст командной оболочке. 
## **Структура команды**
Команду можно представить в виде: команда (-опции) (аргументы). К примеру ls -la var/log означает: 
1. ls - команда для просмотра содержимого в директории
2. -la - две короткие опции записанные вместе 
3. var/log - путь, содержимое которого нужно показать

Коротки опции (одна буква) обычно пишутся с одним дефисом (-l), а длинные с двумя (--all). Короткие опции можно объединять, вместо ls -l -a, можно ls -la. Конкретный набор опций зависит от программы. Опции можно узнать в -h или --help. 
Порядок аргументов критически важен. Например cp source.txt backup.txt копирует из source в backup, если наоборот, то смысл меняется. 
## **Первые три вопроса в терминале**
Когда мы первый раз попадаем в терминал, то почти всегда сначала стараемся ответить на 3 вопроса:
1. Где я нахожусь
2. Что я вижу
3. Как перейти туда, куда мне нужно
