## **Корневая директория**
Точкой отсчета в GNU/Linux является корневая директория **/**. Внутри нее располагаются все файлы и директории. В отличие от Windows, где каждый диск имеет собственный корень (C: или D:) Linux имеет единственное дерево, в которое подключены все диски и разделы (начинается с /). 
В GNU/Linux все (директории, обычные файлы, устройства, сетевые соединения) являются файлами, это значит, что для них используются одинаковые инструменты. Командой cat можно прочитать файл, а можно прочитать данные ядра: `cat /proc/cpuinfo`. При этом существует несколько типов файлов. Тип можно узнать через **ls -l**:
1. *-* - обычный файл
2. d - директория
3. l - специальная ссылка
4. c - символьное устройство
5. b - блочное устройство
6. s - сокет
7. p - FIFO (pipe)
Таким образом директория - файл специального типа. 
В качестве же основных директорий можно выделить следующие: **/etc**, **/var**, **/home**, **/proc**, **/boot**, **/bin**, **/mnt**, **/opt**.

## **Директория /etc**
Хранит основные системные конфигурационные файлы, определяющих параметры работы системы и установленных сервисов (сетевые настройки, политика авторизации, параметры загрузчика и так далее). Важно отличать их от пользовательских конфигураций, которые хранятся (как правило) в ~/.config.
Одним из самых важных компонентов /etc является /etc/passwd, файл выполняющий учет пользовательских записей. Хранение кэшей паролей находится в /etc/shadow, файле с ограниченным доступом. В файле passwd структурированные записи, каждая из которых соответствует отдельной учетной записи (содержит поля разделенные символом *:*):
**username:x:UID:GID:comment:home_directory:shell**
Пример записи: edtechlab_user:x:1000:1000::/home/edtechlab_user:/bin/bash
Учетные записи бывают двух типов: 
1. Обычные пользователи (UID начинается от 1000, созданы для людей, работающих в системе, указана оболочка (чаще всего bin/bash))
2. Служебные учетные записи (Для работы и фоновых процессов, без оболочки (вместо нее указывается /bin/false или /usr/sbin/nologin))
## **Директория /var**
Директория /var предназначена для хранения данных, которые изменяются в процессе работы системы: 
1. /var/log - журнал событий
2. /var/cache - кэш приложений и пакетного менеджера
3. /var/spool - очереди задач
4. /var/www - данные веб-серверов
## **Директория /home**
Личное пространство пользователей, где хранятся документы, файлы, персональные настройки и конфиги. У каждого пользователя отдельная директория, например: /home/bob. Защищены правами доступа (можно воспользоваться повышением привилегий и посмотреть чужую директорию через команду sudo). 
## **Директория /proc**
Директория **/proc** - это псевдофайловая система, которая не хранит данные на диске, а представляет информацию от ядра в виде файлов, следуя принципу Linux, что всё является файлом. Через неё можно получить информацию о запущенных процессах, процессоре, памяти и параметрах ядра. Для каждого запущенного процесса в **/proc** автоматически создаётся директория с его номером (**PID**), а внутри неё лежат файлы с именем процесса(**comm**), его состоянием (**status**) и другое.
## **Директория /boot**
Содержит файлы для загрузки ОС, например ядро Linux (vmlinuz - буква z указывает на то, что образ сжат), начальный RAM-диск (initrd.img), конфигурацию загрузчика и вспомогательные файлы. Без этого система не запустится. При обновлениях создается backup. 
## **Директория /bin**
Лежат исполняемые файлы базовых команд (cat, echo, grep, ls, cp, mv и другие). 
## **Директория /mnt**
Директория, в которой хранятся точки дополнительно подключенных ФС, для корректного отображения в системе. 
## **Директория /opt**
Директория, куда устанавливают сторонние программы, не являющиеся частью стандартной системы.
