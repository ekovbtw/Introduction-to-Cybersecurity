При установке и обновлении пакетов APT загружает данные из репозиториев, адреса которых указаны в конфигурации системы. Если используемый сервер недоступен или загружает данные слишком медленно, его можно заменить зеркалом - другим сервером, содержащим копию репозиториев. В качестве такого сервера настроим зеркало Яндекса.

Откроем файл **/etc/apt/sources.list** с помощью текстового редактора **nano**: `sudo nano /etc/apt/sources.list`

Строки, начинающиеся с символа #, считаются комментариями и не обрабатываются APT. Закомментируем строки с ранее настроенными репозиториями, добавив символ **#** в их начало. После этого добавим адреса зеркал Яндекса:

```
deb https://mirror.yandex.ru/debian/ bookworm main contrib non-free non-free-firmwaredeb https://mirror.yandex.ru/debian/ bookworm-updates main contrib non-free non-free-firmwaredeb https://mirror.yandex.ru/debian-security/ bookworm-security main contrib non-free non-free-firmware
```
