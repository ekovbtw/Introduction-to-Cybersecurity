Первое, что стоит отметить - Linux используется во многих задачах. 
1. Обучение - Linux активно используется для обучения студентов. Их понимания работы Unix систем. Его легко развернуть в виртуальной среде. 
2. Серверы - Linux часто используется для хранения баз данных, API, внутренние сервисы.
3. Облака и контейнеры - Docker и большинство серверных окружений тесно связаны с Linux 
4. Сетевые устройства - Маршрутизаторы, шлюзы, NAS, камеры и IoT-устройства часто используют Linux или Unix-like системы
5. Инструменты по кибербезопасности удобнее запускать на Linux. Возможность увидеть логи, настройки.

## Unix система как источник вдохновения
Все началось с Multics (1964-2000) - многопользовательская ОС. Хоть она и была сложной, но в ней был ряд нововведений: права доступа, многопользовательский режим, иерархическая файловая система, модульная архитектура. В 1969 году Кен Томпсон и Деннис Ритчи начали разработку Unix. Unix была проще чем Multics, компактнее и практичнее. 

В Unix системе был ряд нововведений:
1. Все является файлом - любой процесс, сокет или поток можно представить в виде объекта. 
2. Маленькие инструменты - одна программа делает одну задачу.
3. Композиция команд - соединение команд между собой.
4. Иерархия файлов - файлы и каталоги организованны в дерево.
5. Многопользовательская модель - у каждого пользователя есть свои права, группы и ограничения. 
6. Текстовые конфиги и логи - возможность читать понятные настройки и данные.

Вокруг Unix сформировались три важные ветки:
1. **коммерческая ветка** [**AT&T**](https://www.att.com/) - официальная линия разработки Unix
2. **BSD Unix** - академическая ветка, развивавшаяся в Калифорнийском университете в Беркли
3. **Unix-like** - все остальные системы, не подходящие под [**строгие критерии Unix-системы**](https://www.unix.org/overview.html), но заимствующие ее идеи

## **GNU: пользовательское окружение**
В 1983 году Ричард Столлман начал проект GNU (GNUs Not Unix). Суть проекта была в том, чтобы создать операционную систему не зависящую от оригинального кода Unix, никак не связанную с закрытым кодом AT&T. 
Проект дал: 
1. Shell - командная оболочка для работы с системой. Например Bash. 
2. Coreutils - базовые команды. 
3. GCC - компилятор.
4. glibc - стандартная библиотека C, через которую программы взаимодействуют с системой. 
5. GDB - отладчик программ.
6. make - инструмент для автоматизации сборки программ. 
7. grep, sed, awk - инструмент для поиска, фильтрации и обработки текста.
## Ядро
Пользовательское окружение - оболочка, программы и тд. 
Ядро - управляет процессами, памятью, устройствами, файловой системой и сетью.
Ядро - центральная часть ОС. Находится между программами (Software) и железом (Hardware). 
GNU - не ядро Linux, это набор системных компонентов. 
В 1991 году Линус Торвальдс опубликовал ядро Linux. Благодаря open-source проекту начал быстро развиваться.
![[Pasted image 20260901132650.png]]
Основные компоненты ядра: 
1. Управление процессами - запуск программ, распределение процессорного времени, завершение процессов
2. Управление памятью - выделение памяти и распределение ее так, чтобы процессы не мешали друг другу
3. Файловые системы - чтение и запись файлов на носителях
4. Драйверы - работа с USB, модулями, GPU, и тд
5. Сеть - обрабатывает сетевые соединения, маршрутизацию, сокеты и интерфейсы
6. Права и изоляция - помогает разделять права пользователей, процессы и ресурсы
7. Системные вызовы - дает программам контролируемый способ обращаться к ресурсам системы
Linux - ядро. Система, использующая компоненты GNU и ядро Linux называют GNU/Linux.

GNU/Linux система состоит из: 
1. Оборудование - CPU, RAM, Drive, Network, USB, GPU - физические ресурсы системы
2. Ядро Linux - планировщик процессов, памяти, драйверы, сеть - управляет железом и ресурсами
3. Системные библиотеки - Например, glib - помогают программам обращаться к функциям системы 
4. Командная оболочка и утилиты - Bash, Coreutils, grep, sed, awk - позволяют пользователю управлять системой
5. Системные службы - ssh, логирование, планировщик задач, сетевые сервисы - обеспечивают работу системы в фоне
6. Прикладные программы - Веб-браузеры, базы данных, редакторы кода - решают пользовательские задачи

## Дистрибутивы
Дистрибутив Linux - готовая сборка на базе ядра Linux, включающая в себя репозитории, установщик, системные компоненты, настройки и набор программ.
В дистрибутив входит: 
1. Ядро Linux - управление оборудованием и ресурсами
2. Загрузчик ядра - запускает ядро при включении компьютера
3. Системные библиотеки - нужны программам для работы
4. Командные утилиты - позволяют управлять файлами, процессами, пользователями и сетью 
5. Пакетный менеджер - установка, обновление, удаление программ
6. Репозитории - хранилища пакетов для конкретного дистрибутива 
7. Системные службы - ssh, логирование, другие фоновые процессы
8. Средства безопасности - пользователи, группы, права, обновления, политики доступа
9. Графическое окружение - необязательный слой для работы через GUI 
10. Документация и настройки - помогают установить и обновить систему

## Open-source и лицензии 
Linux развивался в основном благодаря открытому исходному коду. Но открытый код не означает, что с ядром можно делать, что угодно. Существует лицензия - набор правил, по которым автор разрешает другим людям использовать его код.
